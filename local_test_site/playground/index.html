LAB 01

Normal Scenarios

Tempat pengujian alur normal pada komponen dan halaman MyDreamZone. Skenario akan memeriksa apakah interaksi berjalan sesuai perilaku yang diharapkan.

  • Alur penggunaan standar
  • Validasi hasil interaksi dan state UI
  • Evidence untuk setiap hasil pengujian
↑ Kembali ke daftar lab

LAB 02

Negative Test Lab

Area khusus untuk kondisi negatif dan reproduksi kegagalan yang disengaja. Skenario negatif tidak ditempatkan pada homepage normal.

  • Input kosong atau tidak valid
  • Simulasi error yang terkontrol
  • Penanda NEGATIVE TEST dan INTENTIONAL BUG REPRODUCTION
↑ Kembali ke daftar lab

LAB 03

Accessibility Lab

Area untuk memeriksa aksesibilitas interaksi, struktur, dan informasi komponen.

  • Navigasi keyboard dan urutan fokus
  • Accessible name, label, role, dan state
  • Semantik serta perilaku dialog
↑ Kembali ke daftar lab

LAB 04

Responsive Lab

Area pemeriksaan tampilan lintas ukuran layar pada satu website MyDreamZone.

  • Desktop, tablet, dan mobile
  • Overflow, clipping, dan overlap
  • Ukuran target interaksi dan sticky elements
↑ Kembali ke daftar lab

LAB 05

Security Behavior Lab

Area simulasi perilaku keamanan pada lingkungan lokal yang dikendalikan. Tidak ada bypass CAPTCHA, Cloudflare, WAF, atau kontrol keamanan website lain.

  • Endpoint lokal dan skenario allowlist
  • Rate limit serta pencatatan evidence yang aman
  • Berhenti saat batas respons 403 terkonfigurasi tercapai
↑ Kembali ke daftar lab
